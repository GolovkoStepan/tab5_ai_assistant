# M5Stack TAB5 AI Assistant

На текущий момент я имею на руках плату TAB5, аккумелятор для нее и клавиатурный модуль. Техническую документацию можно найти в директории docs.

### Основная идея
ИИ помошник для бытовых задач. Работает с облачной нейронной сетью. Ведет нужную документацию по различным темам. Базовый вариант использования: Очиститель воздуха требует очистку. После очистки фильтра нужно сбросить на нем ошибку. Как именно ее сбросить я не помню и поэтому гуглю инфу. В данном случае наш ИИ помошник может сам найти нужную информацию, ответить мне на мои вопросы и сохранить на sd карте в качестве документа, чтобы больше ее не искать. И так со всеми остальными бытовыми вопросами.

Те агент ведет внутреннюю документацию по различным интересующим меня темам.

### MVP
Реализовать агентский софт для работы на этом устройстве. Должен быть формат диалога, а также инстументы для создания/изменения/удаления md файлов (и, возможно, других типов). Возможность поиска в интернете.

Работа планируется с openai совместимым api.

Натройки wifi подключения и конфигурация соединения с api должны быть доступны на устройстве. 

Файлы будут храниться на sd карте (у меня есть на 4 гигабайта).

Печатать будем на клавиатуре, которая есть отдельно в виде модуля.

Тк есть заводской аккумулятор, нужно также выводить его заряд и возможно предупреждение о низком заряде.

### Дальнейшее развитие проекта

В будущем возможно улучшение софта. Работа с дополнительной переферией, которая есть на плате.

### Текущие задачи, которые на тебе

1) Создать файл AGENTS.md с кратким описанием, текущим статусом и основными командами. Также, в нем должны быть ссылки на технические документы.
2) Ознакомится с документацией в директории docs. 
3) Составить план разработки ПО

Примечания: коммиты и пуш на мне, работаешь в дефолтной ветке по своему плану. Используем релиз теги. Ведем changelog.
Перед коммитом проверяем документацию на расхождения с реализацией, дополняем по необходимости. Гоняем тесты и тп, что будет у нас на github actions. Комметарии в коде и общение на русском языке, ведение документации тоже. По возможности макс используем уже готовые библиотеки от m5stack.
