# M5Stack TAB5 AI Assistant

Прошивка для **M5Stack TAB5** — карманный ИИ-помощник для бытовых задач.
Пишешь вопрос на клавиатуре — он ищет в интернете, отвечает и **сохраняет
найденное в собственный архив markdown-файлов на SD-карте**, чтобы второй раз
не гуглить.

> Очиститель воздуха просит заменить фильтр, а как сбросить ошибку — забыл.
> Ассистент найдёт инструкцию, покажет по шагам и сохранит
> `notes/home/air-purifier-filter-reset.md` со ссылкой на источник.
> Через месяц: «как сбросить ошибку очистителя» → ответ из собственного архива,
> интернет не нужен.

## Что уже работает

Текущая версия — **v1.1.0 «Настройки и быт»**: ассистент ищет в интернете, когда
это нужно для ответа, запоминает найденное в архиве, предупреждает о разряде и
гасит экран без дела. Этап закрыл четыре дыры, найденные чтением кода сразу
после v1.0.0, — ни одна не была в плане: **экран «Параметры»** (`Ctrl+G`: яркость,
таймаут подсветки, раскладка, пороги разряда, таймзона — без компьютера),
**история ввода** в чате (`Alt+↑↓`), **заметка руками** (`Ctrl+N` в архиве) и
**ответ из чата в архив** (`Ctrl+S`), **честные списки** «N из M» со страницами и
поиском по тредам.
Скелет собран и проверен на живой плате: дисплей 1280×720 с кириллицей,
клавиатура A164 с раскладкой латиница/ЙЦУКЕН, SD-карта в 4-bit с записью,
батарея через INA226, Wi-Fi через ESP32-C6 — скан сетей и экран настройки
(`Ctrl+W`) с вводом пароля.

При включении открывается **меню** (`Ctrl+M`) — список разделов и справка по
командам; `Esc` ведёт в чат.

В этой версии есть чат: диалог с моделью через OpenAI-совместимый API со
стримингом, треды на SD, поле ввода и лента сообщений, счётчик токенов,
прерывание ответа по `Esc` (недописанный ответ сохраняется с пометкой
«неполный»), экран списка тредов (`Ctrl+T`: открыть, создать, удалить, поиск
по заголовкам), экран настроек API (`Ctrl+A`) и параметров устройства
(`Ctrl+G`). Ключ API вводится на устройстве и
хранится только в NVS. Время берётся из RTC при старте и сверяется по NTP,
когда поднимается Wi-Fi, — поэтому метки в треде и имена файлов настоящие, в
том числе после перезагрузки без сети. В правом верхнем углу — **системный
трей**: справа четыре палочки уровня сигнала, левее корпус батареи с подписью.
Он виден на всех экранах, тап по значку сети открывает экран Wi-Fi, по
батарее — диагностику. Адрес Wi-Fi в трее не выводится — он живёт на экране
Wi-Fi вместе с именем сети. Процент заряда показывается только на разряде: при подключённом
кабеле `getBatteryLevel()` на Tab5 всегда даёт 100 %, поэтому там пишется
«заряд», а после его окончания — «заряжено». Если при кабеле вынуть
аккумулятор, трей это замечает и показывает прочерк, а не выдуманный заряд:
наличие батареи определяется по току и напряжению отдельно от состояния заряда.
При включении сначала идёт **заставка** — название, полоса прогресса и шаги
запуска (экран, карта памяти, настройки, клавиатура, сеть), — а затем
открывается меню. Два светодиода клавиатуры показывают состояние модели и
питание, и внутри одного уровня светятся одинаково ярко: цвета подобраны по
воспринимаемой яркости, а не по значению канала. Открытый тред
можно очистить по `Ctrl+R` (второе нажатие подтверждает — файл на SD стирается
безвозвратно).

При 429 и 5xx запрос повторяется до двух раз: пауза берётся из `Retry-After`
(не дольше 30 с), иначе 2 и 4 с; в статусе идёт обратный отсчёт, `Esc` работает.
Если же 429 пришёл потому, что **кончились деньги по ключу**, повторов нет — на
экране сразу видно «Лимит трат по ключу исчерпан: 252,42 из 250,00 руб.
Пополните баланс.», отдельной тёмно-красной полосой.

**В v0.3.0 «Документы» появился архив.** Модель получает инструменты над архивом
`/sdcard/notes`: `list_docs`, `read_doc`, `search_docs`, `write_doc`,
`delete_doc`. Агентский цикл (до 8 шагов) показывает каждый вызов в ленте одной
строкой, ошибку инструмента возвращает модели текстом, удаление спрашивает
подтверждение на экране. Документы — markdown с YAML-фронтматтером
(`title`, `tags`, `source_url`, `created`, `updated`), пишутся атомарно через
`.tmp`, `INDEX.md` пересобирается после каждой записи. По `Ctrl+O` открывается
архив: список со страницами, поиск, просмотр с прокруткой и текстовый редактор
(`Ctrl+S`, `Ctrl+Z`); `Ctrl+N` создаёт новую заметку. По `Ctrl+M` открывается меню: переходы во все разделы и полный
список команд — внизу экрана остались только самые частые.
На живой плате пройден сквозной сценарий: агент сам создал заметку, повторный
запрос обновил тот же файл (дата создания удержана, теги и источник не
потерялись), а экран заметок провёл список, поиск, правку и удаление с
подтверждением.

**В v0.4.0 ассистент получил интернет.** Поиск — обычный инструмент
`web_search` рядом с архивными: модель зовёт его, когда для ответа нужны
внешние данные, и только тогда прошивка делает отдельный запрос с плагином
`web`. Найденные страницы приходят в `annotations`, складываются без повторов и
дописываются в конце ответа списком «домен — заголовок», а первый из них
становится `source_url` заметки, если модель не указала свой. Включение и число
источников (1..10) настраиваются на устройстве: `Ctrl+A`, строки «Веб-поиск» и
«Источников в ответе». Поиск платный: провайдер берёт около 2 ₽ за запрос с
плагином и ищет по тексту любой реплики, если плагин в запросе есть — поэтому в
основном запросе его нет никогда, и «привет» стоит копейки, а не два рубля.
Если поиск ничего не дал, в ленте прямо сказано об этом, а не остаётся пустое
место.

**В v0.5.0 «Полировка» устройство стало удобнее в быту.** При разряде оно
предупреждает в полосе сообщений (20 %, 10 %, 5 %; пороги правятся в
`config.json`), а ниже последнего порога сохраняет недописанный ответ и
открытую заметку, гасит экран и выключается. Через две минуты бездействия экран
гаснет и зажигается от любой клавиши или тапа — но не гаснет, пока идёт ответ
модели. Без сети в чате висит подсказка, что доступны архив и история, а не
пустая лента. По `Ctrl+I` открывается **«О программе»**: версия, модель, адрес
API, таймзона, время, память, карта, клавиатура и сеть — то, что раньше искали
через Serial.

Одно место этого этапа проверено только тестами, а не на устройстве: пороги
разряда 20 / 10 / 5 % и выключение при 5 % требуют разрядить аккумулятор до
порога (несколько часов). Это записано как техдолг в `AGENTS.md`; логика
покрыта 15 тестами, шаги проверки — в `docs/HARDWARE_VERIFICATION.md`.

**В v1.1.0 всё, что раньше требовало ноутбука, делается на устройстве.**
Яркость, таймаут подсветки, раскладка, пороги разряда и часовой пояс правятся на
экране `Ctrl+G` («п» в ЙЦУКЕН): `↑↓` — выбор, `←→` — шаг, `Ctrl+S` — сохранить.
Яркость, раскладка и пояс видны сразу, не дожидаясь сохранения, — иначе «убавить
яркость» было бы невидимым действием; уход без `Ctrl+S` возвращает прежние
значения. Порядок порогов `предупреждение > критический > выключение` стрелкой
сломать нельзя: порог упирается в соседний, а не перескакивает его, — иначе
предупреждение о разряде не показалось бы никогда.

`Alt+↑` в поле ввода возвращает предыдущий вопрос, `Alt+↓` — следующий; первый
`Alt+↑` запоминает недописанный черновик и `Alt+↓` возвращает его. `↑↓` без `Alt`
по-прежнему листают ленту: прокрутка нужна чаще, чем повтор вопроса.

В архиве `Ctrl+N` создаёт заметку и сразу открывает редактор — файл получает
служебное имя `inbox/note-ГГГГММДД-ЧЧММСС.md`, а заголовок берётся из первой
строки тела (латинский слаг на 70 клавишах подбирать не нужно). `Ctrl+S` в чате
кладёт последний ответ в `inbox/answer-…` вместе с источниками. Списки больше не
обрезаются молча: видно «N из M», страницы листаются `← →`, в тредах есть поиск
по заголовкам (`/`).

**В v1.0.0 новых возможностей не было — это была стабилизация.** Проверено, что
заводская прошивка восстанавливается из снятого дампа (и что вместе с ней
стирается `nvs`, то есть ключ API и Wi-Fi вводятся заново). Долгая сессия
пройдена скриптом: 20 ходов подряд, память не растёт. Проход по дефектам
исправил два: бюджет истории не считал вызовы инструментов (до 34 КБ за ход),
из-за чего на длинном треде тело запроса не собиралось (теперь вызовы
считаются, а если тело всё равно не влезло, бюджет ужимается и сборка
повторяется — Р-047), и тред, дошедший до 200 сообщений, отвечал технической
строкой без выхода (теперь «Тред заполнен (200) — Ctrl+N начнёт новый», а для
приёмки скриптом есть команда `new` — Р-048).

Для приёмки без клавиатуры есть ввод с компьютера по Serial: `ask <вопрос>`
отправляет вопрос в текущий тред, `thread` распечатывает тред с карты
бесплатно, `wifi off` / `wifi on` выключают и включают радио — так проверено
поведение без интернета, без человека у экрана. `api <адрес>` подменяет адрес
API на время прогона: с ним «пустая выдача» и отказ поискового сервера
проверяются бесплатно на фальшивом сервере `scripts/fake_api.py`, а не живым
вопросом (тот никогда не отдаёт пустую выдачу). `screen <имя>` открывает
экран — тот же `Ctrl+I` или меню, но из скрипта: так экран «О программе»
проверен счётом пикселей, а не глазами. `tz <зона>` правит таймзону, `new`
начинает новый тред — когда прежний дошёл до 200 сообщений, `save` кладёт
последний ответ в архив. `screen settings` и `dev <шаг>` открывают экран
параметров и жмут на нём стрелки — так проверены яркость и пороги разряда;
этой командой сразу нашёлся дефект: `dev warn+5` срабатывал как `+1`, потому что
`battery_step` делала ровно один шаг при любом `delta`.

Полный план и статус — в [`docs/DEVELOPMENT_PLAN.md`](docs/DEVELOPMENT_PLAN.md),
измеренные значения — в
[`docs/HARDWARE_VERIFICATION.md`](docs/HARDWARE_VERIFICATION.md).

### Почему не ESP-IDF и не LVGL

- **ESP-IDF** дал бы больше контроля над памятью, но батарею, RTC и питание
  пришлось бы писать самим — M5Unified отдаёт это бесплатно.
- **LVGL 9.2 не содержит ни одного готового шрифта с кириллицей** (проверено
  разбором cmap: Montserrat, DejaVu, SimSun — только ASCII и CJK). В M5GFX
  кириллица включается одной строкой.

Подробнее — [`docs/DECISIONS.md`](docs/DECISIONS.md), решения Р-001…Р-003.

## Быстрый старт

```bash
# 1. Собрать
pio run -e tab5

# 2. Прошить (USB-C)
pio run -e tab5 -t upload

# 3. Смотреть лог
pio device monitor -b 115200

# 4. Прогнать тесты логики (без железа)
pio test -e native

# 5. Проверить всё, что проверяет CI (формат, cppcheck, тесты, сборка)
./scripts/check.sh

# 6. То же в контейнере — максимально близко к CI
./scripts/check.sh docker
```

Первая сборка в контейнере долгая: скачивается Arduino core и ESP-IDF
(несколько ГБ). Тулчейн кешируется в docker-томе `tab5-pio-core-ubuntu-24-04`,
поэтому повторный прогон занимает полторы минуты вместо восьми.

`./scripts/check.sh docker` проверяет ровно то же, что CI: формат, cppcheck,
тесты и сборку прошивки. Сборка идёт в копии репозитория: `.pio` с хоста
содержит объектные файлы macOS, и Linux-линкер получил бы чужой формат.

**Перед коммитом** достаточно `./scripts/check.sh`: скрипт ставит
зафиксированную версию clang-format через pip, поэтому результат совпадает с CI
на любой ОС. Голый системный `clang-format` не используйте — в Ubuntu 24.04 это
18.1.3, а на macOS 21.0.0, и они расходятся в форматировании.

**Перед первой прошивкой** снимите дамп заводской прошивки — обратно её взять
негде:

```bash
~/.platformio/packages/tool-esptool/esptool --chip esp32p4 -p /dev/cu.usbmodem* \
    -b 921600 read_flash 0 0x1000000 backup/tab5-factory-16mb.bin
```

## Ограничения MVP

Не входит в MVP, запланировано: голос (STT/TTS), камера, рендер markdown на
экране, векторный поиск, умный дом — 2.0.0; OTA-обновления — 1.2.0.

Без интернета устройство остаётся работоспособным: документы и история доступны,
поиск и диалог сообщают об отсутствии сети.

Ввод в MVP — только с клавиатуры A164. Голосового ввода нет.
